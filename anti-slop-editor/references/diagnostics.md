# Diagnose the failure, not the author

Use a pattern only when it harms this passage. A word or punctuation mark is not
proof of AI authorship. These are editorial tests, not a statistical detector.

| Visible symptom | Test | Repair |
| --- | --- | --- |
| Generic era opening | Could it open an unrelated article unchanged? | Begin with the actual issue or supplied scene. |
| Importance without substance | What specifically changes, for whom? | State the supported change or remove the evaluation. |
| Vague authority | Who made this claim, and where? | Retain real attribution; flag missing evidence. |
| Invented precision | Can this number or anecdote be traced? | Restore the supported statement; never invent specificity. |
| Abstract action | Who does what to which object? | Use available actors and concrete verbs. |
| Fake causal bridge | Does evidence justify "therefore" or "because"? | Keep sequence or association without asserting cause. |
| Ornamental contrast | Does "not X but Y" correct a real misconception? | Preserve real contrast; otherwise state the point. |
| Repeated triads | Are the three items distinct and necessary? | Keep the actual number of ideas. |
| Synonym cycling | Are different labels naming the same thing? | Use stable terminology and unambiguous references. |
| Promise instead of content | Is the passage announcing an explanation? | Provide it, unless a roadmap aids navigation. |
| Over-symmetrical sections | Does each section deserve the same weight? | Allocate space by relevance and evidence. |
| Staccato drama | Are fragments creating emphasis without an idea? | Reconnect the thought; keep purposeful emphasis. |
| Wordy throat-clearing | Would deleting the wrapper change meaning? | Remove the wrapper, keep any real qualification. |
| Inflated headline | Does the body deliver the exact promise? | Narrow the headline to what the body supports. |
| Repeated conclusion | Does it add synthesis, consequence, or closure? | End earlier or state the actual implication. |
| Faux profundity | What remains when the aphorism is flattened? | Write that claim and its limits. |
| Feature fog | Can a reader tell what the product actually does? | State capability, relevant user, and known boundary. |
| Fake intimacy | Is the feeling or experience genuinely the author's? | Remove invented persona, not legitimate warmth. |
| Formulaic politeness | Is courtesy functional in this relationship? | Keep useful courtesy; remove performative flattery. |
| Hedging pile-up | Which qualification actually reflects uncertainty? | Remove duplicates; keep all distinct limits. |
| False certainty | Did editing strengthen the source's confidence? | Restore modality, attribution, scope, and exceptions. |
| Translationese | Is target syntax imitating the source unnecessarily? | Recast naturally without changing propositions. |
| Formatting as content | Would the section still have substance unbolded? | Improve content first; keep useful navigation. |
| Chatbot residue | Is this a response wrapper inside a publishable artifact? | Remove it from the artifact, not from quoted examples. |
| Context leakage | Does the text assume the reader saw the prompt or chat? | Supply necessary context without exposing private instructions. |
| False completeness | Are "all," "always," or "definitive" justified? | Describe the actual scope. |
| Overcompression | Did the edit remove the reason, caveat, or next action? | Restore what the reader needs, even at greater length. |
| Automatic selling | Is this a showcase, reference, or public-interest article? | Remove sales pressure; match the actual purpose. |

## Original diagnostic examples

Input: "Dalam era digital yang dinamis, fitur ini menjadi solusi inovatif untuk
meningkatkan efisiensi alur kerja." No capability or evidence is supplied.
Repair: Do not invent a capability. Ask for the feature's actual function, or
flag the sentence as uninformative during an audit.

Input: "The export includes CSV and PDF, reflecting our unwavering commitment
to empowering modern teams."
Edit: "The export includes CSV and PDF." The trailing claim adds no capability.

Input: "The delay was not caused by payment processing but by address validation."
Keep the contrast when it reflects the evidence. It is explanatory, not slop.

Before rejecting a phrase, check whether it appears inside a quote, title,
example, legal clause, brand name, or text being analyzed. Do not rewrite those
spans merely because they match a diagnostic pattern.
